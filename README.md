# AutoResponder (app)

Android-приложение: автоответчик на звонки и SMS, когда телефон «закрыт»
(режим «Не беспокоить» или собственное расписание).

## Что делает (v1)
- **Звонки** — держит роль `CALL_SCREENING`; в режиме «закрыто» отклоняет входящий
  (если номер подходит под маску страны) и отправляет авто-SMS.
- **SMS** — принимает входящие (`SMS_RECEIVED`) и отвечает.
- **Маска стран** — реагирует только на номера с разрешённым префиксом (напр. `+420`),
  остальные и буквенных отправителей игнорирует.
- **Ответ** — при интернете короткий ответ через LLM (Ollama по умолчанию, либо
  OpenAI-совместимый / Claude по ключу), иначе — офлайн-шаблон.
- **Язык** — автоопределение (ru/cs/en) по тексту SMS; LLM отвечает на языке клиента.
- **Лимит сегментов** — ответ гарантированно укладывается в ≤6 SMS-сегментов
  (учитывается, что UCS-2 для ru/cs вмещает вдвое меньше символов, чем GSM-7).
- **Анти-петля** — не более одного авто-ответа на номер за cooldown-окно.

RCS и мессенджеры (WhatsApp/Telegram через `NotificationListenerService`) — заготовка, в v1 не активны.

## Сборка
- `.github/workflows/build.yml` — debug APK на каждый push (артефакт).
- `.github/workflows/release.yml` — release APK при теге `v*` (в Releases).

Локально: `./gradlew assembleDebug` (нужен Android SDK + JDK 17).

## Установка
Через KernelSU-модуль (рекомендуется): он ставит APK, выдаёт права, назначает роль,
включает доступ к уведомлениям, добавляет в Doze whitelist.
Модуль: https://github.com/davnozdu/autoresponder-ksu-module

Вручную: `adb install AutoResponder-*.apk`, затем в приложении выдать права и роль.

## Устройство (проверено)
OnePlus 15 (CPH2745), Android 16 / OxygenOS V16.1.0, KernelSU.
